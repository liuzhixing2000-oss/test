# BTC Layered Breakout Probability Study

Railway Start Command:

    python railway_layered_runner.py

Main outputs:
- btc_layered_summary.txt
- btc_layered_probabilities.csv
- btc_layered_oos_stability.csv
- btc_layered_yearly.csv
- btc_layered_oos_descriptive_shortlist.csv
- btc_layered_recent_events.csv
- btc_layered_events.csv

This study compares +1%, +1.5%, +2%, +3%, +4% forward targets and -1% adverse movement,
with chronological discovery/OOS separation.
